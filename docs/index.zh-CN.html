简体中文English

四个运动部件

除此之外，没有任何东西决定谁运行什么

PCS持有主机、部署计划、Profile、Secret 引用和审计。只写期望状态，从不直接调用 Docker。
host-runtime运行在每台主机上。验证签名命令、创建容器并上报资源。只出站。
调度机状态权威。在递归树中排队、准入、发租约、fencing、派发和记录。
构建机唯一的工作角色。领取任务，运行 Agent 适配器或确定性 Shell，流式输出并上传产物。

快速开始

单机 Compose · Node 22+ · PostgreSQL 16 · Docker 24+

cd deploy
cp .env.example .env
mkdir -p keys tokens data/postgres data/artifacts

ssh-keygen -t ed25519 -N "" -f keys/scheduler
ssh-keygen -t ed25519 -N "" -f keys/builder
for os in 20 22 24 26; do cp keys/builder.pub "keys/builder$os.pub"; done

docker compose -f compose.yaml --env-file .env up -d --build

然后打开管理端。

添加主机、部署调度机、添加构建机，然后提交第一个任务。需要让设备用 curl 调用主机时，再接入侧载。
